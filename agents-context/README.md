# agents-context

Histórico de tudo que a IA fez neste projeto. Cada pedido que cria, altera ou exclui algo gera um
arquivo novo aqui, com data e hora no nome (`AAAA-MM-DD_HH-MM_descricao-curta.md`).

As regras e o modelo do arquivo estão na seção 4 do [`AGENTS.md`](../AGENTS.md).

- Os arquivos nunca são editados nem apagados depois de criados.
- Ordenados pelo nome, eles formam a linha do tempo do projeto.
- Nada de dados pessoais, trechos de gravação ou senhas aqui.
